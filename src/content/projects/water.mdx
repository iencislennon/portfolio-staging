## Context

The Ili River feeds Lake Balkhash, and water storage there matters for agriculture, energy and ecosystems. The project was built as a demo prototype for the Oxford Saïd Global Climate Tech Challenge 2026 (Water Scarcity track).

## My contribution

I built the whole project: data processing, the Random Forest downscaling, the validation against DAHITI, and the Streamlit dashboard. All commits in the repository are mine.

## Constraints

GRACE has a native resolution of about 55 km and observes total storage for the whole basin. The independent check uses a single lake-level series, which measures a different physical quantity.

## Decisions

- **Validate against something the model never saw.** DAHITI lake-level altimetry is an external signal, compared as standardized series with a fitted two-month shift.
- **Report the gap.** The model scores R² 0.946 on its own test split and 0.349 against DAHITI. The site shows both, and treats the second as the evidence.
- **Describe the output honestly.** The 500 m map is a model-based downscaling of a coarse signal using finer features, not a 500 m measurement.

## Evaluation

Pearson correlation with Lake Balkhash level is 0.6745 (p ≈ 1e-30) over 221 monthly points from 2002 to 2024, giving R² 0.349. The validation report notes that the model uses the previous month's GRACE value as a feature, which makes the internal test score optimistic.

## What failed

The internal score is far stronger than the independent one, and the reason is understood: an autoregressive feature plus a basin-wide signal compared against a single lake. The README previously contained placeholder clone URLs, which I replaced. Live and demo data paths are still mixed in one code path.

## Impact

None claimed beyond the validation above. This is a research prototype with a moderate, documented agreement against an independent source.

## Next iteration

Separate demo and live data paths, add tests for features, the temporal split and dashboard startup, and re-validate without the autoregressive feature.

## Reproducibility

Clone the repository, `pip install -r requirements.txt`, and run `python run_pipeline.py`; the processed predictions and validation report are included under `data/processed` and `assets`.
