## Context

Almaty sits in a mountain bowl, burns coal for heating and has severe winter smog. The project predicts the next day's PM2.5 from historical station data collected through the OpenAQ API.

## My contribution

I built the whole pipeline: data fetching, feature construction, the Ridge, Random Forest and Gradient Boosting models, and, in this polish pass, the corrected evaluation and its tests. All commits in the repository are mine.

## Constraints

Public sensor data with gaps and station-level differences, no weather inputs, and an API key needed to refresh the data.

## Decisions

- **Split by date, not by position.** Every test row must be later than every training row.
- **Lags from the past only.** The one-day lag, seven-day lag and trailing seven-day mean exclude the current value.
- **Station encoding fit on train only.** The target encoding of each station uses training rows, with the global training mean as fallback.
- **Compare against a simple baseline.** Ridge regression is kept as the reference model.

## Evaluation

The evaluation is the part that changed. Five tests build synthetic station data and check that the split is chronological, that lag and rolling features match a manual computation, that target encoding uses only training rows, and that missing values are dropped.

## What failed

The first version sorted rows by station, month and day-of-year and ignored the year. A split with `shuffle=False` on that order is not a chronological holdout, and lag features could pull values across years. The accuracy figures reported at that time came from this flawed split, so I have withheld them rather than repeat them. They need a re-run on a fresh data export.

## Impact

None claimed yet. The value of this project today is a pipeline whose evaluation can be trusted; the accuracy numbers will be published after the re-run.

## Next iteration

Re-run on a fresh export, add seasonal and per-station error analysis against a persistence baseline, add weather features, and ship a small demo with a model card.

## Reproducibility

`pip install -r requirements.txt`, fetch data into `data/raw/Almaty_PM2.5.csv` with the included script (needs an OpenAQ key), then `python train.py`. The tests run without the data: `pytest tests`.
